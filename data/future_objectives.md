# WiseClaw OS: Future Objectives Roadmap (v5.0 & Beyond)

## Phase 5.0: The Sovereign Intelligence (PAI Architecture)

### 1. Proactive Autonomy (The Sentinel Loop)
- [ ] **Thinking Cycles:** Implement background loops for Manager and Researcher to anticipate needs.
- [ ] **Intelligence Briefings:** Automated monitoring of GitHub/X with daily reports in `#investigacao`.
- [ ] **Self-Diagnostic:** Proactive health checks and server optimization without user triggers.

### 2. Multimodal Integration (Voice & Vision)
- [ ] **Voice Interface:** Telegram voice-to-voice integration (STT -> LLM -> TTS) for natural interaction.
- [ ] **Visual Operator:** Real-time UI analysis for the Operator agent to assist in live debugging and software config.
- [ ] **Local Vision:** Integration of Moondream/Llava for private, offline image processing.

### 3. Self-Evolution (Recursive Improvement)
- [ ] **Self-Refactoring:** Automated weekly code audits of the `/src` directory by Coder and QA agents.
- [ ] **Skill Acquisition:** Automated discovery and integration of new MCP servers and modular skills.
- [ ] **Performance Tuning:** Automated benchmarking and latency reduction across all agent chains.

### 4. Neural Visualization (Knowledge Graph 3D)
- [ ] **3D Knowledge Graph:** Transform the dashboard into an interactive 3D map of memories and tasks.
- [ ] **Neural Grid:** Real-time visualization of inter-agent communication and context saturation.

### 5. PAI Core: Context-First & Layered Memory
- [ ] **5D Context Injection:** Every request informed by Mission, Projects, Challenges, Preferences, and History.
- [ ] **Layered Memory:** Implementation of Hot (Recent), Warm (Semantic/Chroma), and Cold (Archive/Markdown) tiers.
- [ ] **Middleware Hooks:** Intercepting operations for security (Sentinel) and lifecycle events before tool execution.

### 6. Sovereignty & Mastery (Code First, Prompts Last)
- [ ] **Tool Hardening:** Prioritize Python/Bash tools over prompt-based instructions for deterministic outcomes.
- [ ] **Local Sovereignty:** Expand Ollama usage for routine tasks to preserve premium tokens and ensure privacy.
- [ ] **Purpose-Driven Logic:** Integrate a 'Values & Purpose' section in the Constitution to guide autonomous decisions.

## Strategic Synthesis: The PAI Transition
The goal of WiseClaw OS v5.0 is to transition from a **Reactive Agent Factory** to a **Proactive Personal AI Infrastructure (PAI)**. 

**Key Pillars:**
1. **Persistence:** Memory that never forgets and context that shapes every interaction.
2. **Verifiability:** Every action follows the `Observe -> Think -> Plan -> Build -> Execute -> Verify -> Learn` cycle.
3. **Sovereignty:** Total control over data and execution through local models and code-first skills.
4. **Proactivity:** A system that works for the Enabler even when not being directly addressed.
